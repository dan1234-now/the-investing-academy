The Investing Academy

The Investing Academy is an educational website that's designed to help people learn the fundamentals of investing, specifically in their ability to recognize candlestick patterns.

Features

- Investing Lessons: Learn the foundational investing concepts, candlestick charts, and risk management.
- Candlestick Chart: Explore a simulated chart to learn how price movements are represented on real-world graphs and predict trends.
- Flashcards: Review important investing concepts and reinforce learning of things like candlesticks
- Quizzes: Test your knowledge and learn from answer explanations. Application is key!
- Compound Growth Calculator: Explore how hypothetical investments can grow over time through compounding (shifts your perception of time and money)
- Responsive Interface: Navigate the learning experience across desktop and mobile devices (hopefully will be great both ways).

How It Was Built

The website uses HTML, CSS, and JavaScript to create an interactive, browser-based learning experience. HTML provides the page structure, CSS handles the visual design and responsive layout, and JavaScript powers interactive learning activities and investing tools.

At the start, a lot of AI was used, but over time there will be more and more human code. The project is designed to run without requiring any backend server or user account. Chart data is simulated for educational purposes rather than being presented as live market data.

How to Run

Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No package installation or build process is required for the basic website.

Run Online

Visit the project's published website through its GitHub Pages URL, if deployment is enabled.

Project Goals

The goal of The Investing Academy is to make investing concepts easier to understand through interactive lessons, practice activities, and educational tools.

This project is intended for educational purposes only. It does not, however, execute trades or provide personalized financial advice.
